Your degree preparation

Computer Engineering prep

A practical 12-week starting plan for UTEL Global/Mexico’s Computer Engineering program. Learn the basics, make things, and return to topics that need more time.

Learning pathRunning PythonFoundationsErrorsPlanningSmall projectsEngineering prep
A flexible starting pace: Aim for 6–8 hours a week over several sessions: about 2 hours learning concepts, 2–3 hours coding or hands-on work, 1–2 hours on math, and 30–60 minutes reviewing. Repeat a week or take longer whenever you need to. These are preparation lessons, not official UTEL courses or a guarantee of admission or credit.

How to study each week

  1. Learn: Read the listed concepts. Use the linked guide section when you need a refresher.
  2. Practice: Work through the task yourself. Plan before typing and use hints only when useful.
  3. Check: Explain the idea in your own words, test your work, and revisit anything uncertain.
  4. Review: Return to earlier topics and the review queue. Check off a week when you’ve reviewed it; your checkmarks stay in this browser.

Use the Python playground for small programs. Week 8 and 9 file and database tasks are best done using a local Python installation; the browser playground may not retain files between runs.

The lesson plans

Build your foundation

Each week includes a concept, an activity, and a readiness check. The order is a suggested route, not UTEL’s official course sequence.

1
Week 1

Run Python and think in steps

Learn: Files, the interpreter, output, variables, and arithmetic; integer operations, fractions, and order of operations.

Do: Run a .py file or use the playground. Create a program that displays a name and calculates the cost of three items. Work out 3 + 4 × 2 and (3 + 4) × 2 by hand, then check in Python.

Ready to move on? Explain what runs your code, trace its output, and change a value without breaking the program.

2
Week 2

Input, types, and equations

Learn: Strings versus numbers, input, type conversion, simple equations, and units.

Do: Build a tip or bill-splitting calculator that asks for values. Solve 3x + 5 = 20 by hand; check your answer by substitution. Try decimals and an unexpected input.

Ready to move on? Explain why input starts as text and show how you tested a normal and an unusual value.

Open Running Python →

3
Week 3

Decisions and logic

Learn: Comparisons, Boolean values, if/elif/else, truth tables, and logical AND/OR/NOT.

Do: Make a program that gives different advice based on an entered temperature. Write a two-input truth table for AND and OR. Test boundary values on either side of your chosen cutoff.

Ready to move on? Predict which branch runs before executing it, including a value exactly on a boundary.

Open Dictionary →

4
Week 4

Loops and problem solving

Learn: for and while loops, counters, termination, and translating a problem into steps.

Do: Plan and build a guessing game with a fixed secret number and repeated attempts. Trace the loop on paper for a wrong guess and then a correct one. Ensure the loop has a clear way to stop.

Ready to move on? Explain how the loop changes state and why it eventually stops for a correct guess.

Open Planning →

5
Week 5

Collections and data

Learn: Lists, dictionaries, indexing, loops over collections, and basic descriptive statistics.

Do: Build a score tracker that stores at least five scores and displays the minimum, maximum, and mean. Calculate the mean on paper first and compare it with your program.

Ready to move on? Explain the difference between a list index and a dictionary key and test an empty or missing entry.

Open Dictionary →

6
Week 6

Functions and debugging

Learn: Parameters, return values, scope, errors, tests, and reading tracebacks.

Do: Split your score tracker into small functions. Test each with ordinary values and a boundary case. Introduce and then fix a NameError or TypeError; write down what the message told you.

Ready to move on? Describe inputs and output for each function and explain a bug you diagnosed.

Open Understanding errors →

7
Week 7

Algorithms and data structures

Learn: Algorithms, searching, sorting, step counting, and a first look at efficiency.

Do: Write a function that finds a value in a list by checking items one at a time. Count comparisons for a first-item match, last-item match, and missing item. Compare with a built-in search.

Ready to move on? Trace your search for a short list and explain why longer lists can take more work.

Open Planning →

8
Week 8

Objects, files, and program design

Learn: Classes and objects as a first look at object-oriented programming; reading and writing files.

Do: Design a simple book or task with a few attributes and a behavior. Build a small collection manager; save and load data with a local Python installation. Try a missing file and describe what should happen.

Ready to move on? Explain the difference between a class and an instance, and demonstrate that saved data can be loaded again.

Open Small projects →

9
Week 9

Databases and data modeling

Learn: Tables, rows, columns, keys, relationships, and basic SQL; percentages and interpreting data.

Do: Sketch two related tables for students and courses, with a way to connect them. Use Python’s built-in sqlite3 in a local Python file to create a small table, insert a few rows, and select them. Calculate a percentage from the results.

Ready to move on? Explain what a key identifies and show a query that filters records. Keep sample data fictional.

10
Week 10

Computer architecture and digital systems

Learn: Bits and bytes, binary, logic gates, CPU, memory, and the fetch–decode–execute idea.

Do: Convert decimal 13 to binary and binary 1010 to decimal by hand, then check with Python. Make truth tables for AND, OR, and NOT, and describe how a CPU and memory cooperate.

Ready to move on? Explain a bit versus a byte and trace one simple instruction at a high level.

Open Foundations →

11
Week 11

Operating systems and networks

Learn: Processes, files, operating systems, IP addresses, clients, servers, and safe use of networks.

Do: Draw the path of a browser request to a website and back. Identify your operating system, a file path, and a running program; describe their roles. Explain how DNS helps a browser find a service.

Ready to move on? Explain the difference between a program and a running process, and describe a client/server exchange.

Open Running Python →

12
Week 12

Math, physics, and a capstone

Learn: Review algebra and functions; introduce rates of change, vectors, probability, and basic voltage/current/resistance concepts.

Do: Plan and build a small inventory or study tracker using functions, a collection, and tests. Graph or tabulate y = 2x + 1 for three inputs; calculate the probability of a chosen side of a fair six-sided die. Explain voltage, current, and resistance using an analogy.

Ready to move on? Demonstrate your project, explain one design decision, and list three topics that need more review.

After these 12 weeks

Continue with algebra, linear algebra, calculus, physics, electronics, algorithms, databases, networks, operating systems, object-oriented programming, and computer architecture. Return to the areas that felt difficult and build longer projects as your confidence grows.

Free learning resources: Khan Academy math lessons for algebra, probability, and calculus; Khan Academy physics; and the Python sqlite3 documentation for the database activity. Use these alongside the guide and work at your own pace.

Curriculum reference: This independent plan is informed by the subjects listed in UTEL Global’s Bachelor in Computer Engineering program sheet. Confirm your own course sequence and requirements with UTEL, since programs and versions can change.
