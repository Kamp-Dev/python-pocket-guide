Coding is giving precise instructions. These building blocks explain how Python reads those instructions, and why small marks matter.

Instructions and order

Python normally runs statements from top to bottom. A statement is an instruction, such as assigning a value or calling a function. Decisions and loops can change which instructions run and how often.

name = "Sam"
print(name)

First the name is saved; then its value is displayed.

Expressions and values

A value is a piece of information, such as 7 or "hello". An expression is code Python can evaluate to produce a value. For example, 2 + 3 produces 5.

score = 2 + 3
print(score)

The calculation on the right is evaluated before the result is assigned to the name.

Quotes make text

Single or double quotes mark a string: text Python treats as a value. Both ends need matching quotes.

name = "Sam"
print('Hello!')

name refers to a variable; "name" is the actual text “name.” To put an apostrophe inside text, you can use double quotes around it: "Let's go!".

Names and assignment

A variable name refers to a value. Choose a meaningful name, such as total_price. Names cannot contain spaces or begin with a number, and Python treats uppercase and lowercase as different.

A single = assigns a value; == compares two values.

score = 7
print(score == 7)

Parentheses, brackets, and braces

( ) can call a function or group a calculation. [ ] can create a list or access an item. { } can create a dictionary or a set.

print(2 + 3)
colors = ["blue", "green"]
print(colors[0])

Each opening mark needs the right closing mark. Lists begin counting at index 0.

Indentation and colons

A block is a group of instructions that belong together. A colon often begins a block after an if, loop, or function. Indent the lines inside it consistently; four spaces are common.

if score > 5:
    print("Nice work!")
print("Done")

The first print belongs to the decision. The second is outside it.

Operators and types

Operators do jobs: + adds numbers, * multiplies, and > compares. The type describes what kind of value something is: 3 is a number; "3" is text.

input() returns text. To do number math with a suitable answer, convert it with int() or float().

Comments and readable code

A # starts a comment outside a string. Python ignores that comment when it runs your program. Use comments to explain an idea or why a choice was made.

# Keep the starting score
score = 0

Spaces and descriptive names also make code easier for a person to read.

Try it yourself

In the practice playground, create a variable containing a number, use it in a calculation, and display the result. Change the number and predict what will happen before running it again.
