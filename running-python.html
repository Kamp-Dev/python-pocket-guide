Running Python

Learning pathRunning PythonFoundationsErrorsPlanningSmall projects

A Python program can start with a line like print("Hello!"). The interpreter is the tool that reads and runs it.

Meet the pieces

Python interpreter: the program that runs Python instructions.

Terminal: a text window where you can give your computer commands and see results.

Python file: a saved collection of instructions, usually with a .py ending.

Editor: a place to write a file, such as VS Code. Your Pocket Guide playground runs Python in the browser.

Try a line in the terminal

  1. Open a terminal. On Windows, you can open PowerShell or Command Prompt.
  2. Type python and press Enter. On Windows, py may work instead; on macOS or Linux, try python3.
  3. When you see >>>, type the line below and press Enter.
print("Hello!")

You should see Hello!. Type exit() to leave Python and return to your normal terminal.

Run a saved file

  1. Create a plain text file called hello.py and put the print line above in it. Save it.
  2. Open a terminal in the folder containing the file.
  3. Run the file using the command for your computer.

Windows:

python hello.py

macOS or Linux:

python3 hello.py

On Windows, py hello.py may also work.

Use VS Code

  1. Install Python and the Microsoft Python extension for VS Code.
  2. Open or create a .py file and write your code.
  3. If asked, select a Python interpreter, then choose the Run Python File play button. Your output appears in the terminal.

The extension helps VS Code work with Python; Python itself is installed separately.

If something goes wrong

Python isn’t recognized? It may not be installed or available to the terminal. Install Python, reopen the terminal, and try again.

File not found? Check the filename and whether the terminal is in the folder containing it.

SyntaxError? Python couldn’t understand the structure of the code. Check quotes, parentheses, spelling, and the indicated line. For example, an unterminated string literal often means a closing quote is missing.
