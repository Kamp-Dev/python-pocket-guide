Plan before you code

Learning pathRunning PythonFoundationsErrorsPlanningSmall projects

Before writing code, turn your idea into small, testable steps. You don’t need the perfect plan—just a useful place to start.

1

Describe the goal

Write one sentence about what the program should accomplish. What should happen from the user’s point of view?

Example: “Ask for a name and display a personal greeting.”

2

Identify input and output

Input: What information does the program need? Output: What should it show or return?

For the greeting: the input is a name; the output is a greeting that includes that name.

3

List the steps

Write the actions in everyday language, in order. This rough plan is sometimes called pseudocode; Python won’t run it until you turn it into actual code.

Ask for a name
Remember the answer
Show a greeting with that name
4

Choose your tools

Look at each step and pick a concept you know. Asking suggests input; remembering suggests a variable; showing something suggests output. Use the dictionary if you forget a tool.

5

Build one piece at a time

Write a small part, run it, and make sure it behaves as expected before adding the next part. A program can be built one working step at a time.

6

Test and improve

Try a normal answer, a different answer, and an unusual one. For a name, what happens with a blank entry? Decide what your program should do, then revise it.

If you hit an error, use the error guide to find a clue.

Your turn: plan a mini program

Imagine a program that asks for two numbers and displays their total. Before typing code, answer these questions:

  1. What are the inputs and what output do you want?
  2. What steps will the program follow?
  3. What type of value does a typed answer start as? What might you need to do before adding?
  4. What two sets of numbers can you use to check the result?
Need a hint?

Separate collecting the answers from turning them into numbers and calculating the result.

Try your plan in the playground, then explore the small projects.
