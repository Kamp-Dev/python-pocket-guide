Small projects

Learning pathRunning PythonFoundationsErrorsPlanningSmall projects

Turn individual concepts into programs. Write your own solution, run it, and compare the result with the checks. Open a hint only if you want a nudge.

Before you code: Say what the program needs to do in plain English. Break it into small steps, test as you go, and change one thing at a time. For a worked example, see Plan before you code. These projects are self-check activities; their results are not automatically graded.

Open the practice playground →

1

Personal greeting

Use: input, variables, and print.

Ask for a person’s name, then greet them using the name they entered.

Check: Try two different names. Does the greeting change each time?

Need a hint?

Save the answer first; then include that saved value in the message you display.

Stretch: Ask a second question and include that answer too.

2

Weather advice

Use: input, comparisons, and if/else.

Ask whether it is raining. Give one suggestion if the answer is yes and a different suggestion otherwise.

Check: Run it with “yes,” then again with “no.” Does the advice change?

Need a hint?

Compare the answer to the word you’re looking for, then decide which branch should run. Think about capital letters, too.

Stretch: Handle unexpected answers with a helpful message.

3

Favorite things

Use: lists, loops, and print.

Make a list with at least three favorite things. Display each item on its own line, then show how many items are in the list.

Check: Add another item. Does the count change and does the new item appear?

Need a hint?

A loop can visit each item, and a built-in tool can tell you the length of a collection.

Stretch: Let a user add an item before you display the list.

4

Reusable calculator

Use: functions, parameters, return, and arithmetic.

Create a function that takes a price and a quantity and returns their total. Call it with at least two different sets of numbers and display the results.

Check: A price of 4 and quantity of 3 should give 12. Try another pair you can calculate yourself.

Need a hint?

Think about what information your function needs to receive and what single result it should hand back.

Stretch: Ask the user for the values and account for input arriving as text.

Finished a project?

Change a requirement, test an unusual input, or explain your program out loud. Then try a code challenge or visit your review queue.
